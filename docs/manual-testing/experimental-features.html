How to use this page

  • Go top to bottom. Start with Setup; most other sections need it.
  • For each test choose Pass, Fail, Blocked (you could not run it) or Skip (not applicable). For a Fail, say what you saw in What happened and pick a severity. Add an idea if you have one.
  • Everything is saved automatically in this browser. At the end use Download report at the bottom and send me the file.
  • Phrases in quotes are examples. A model drives the assistant, so exact replies vary: judge each test by the described outcome. If a result is surprising but not clearly wrong, mark Fail anyway and explain: that is what I want to hear.
  • Switch a feature off again after its section if you want a clean start for the next one.

Make this page talk

Vox listens through your microphone. If this page talks through speakers while you test dictation or conversation, Vox may hear it. Use headphones, or only press Next after the page has finished talking.
  • Guided run: press the Guided run (talks) button. The page reads one step at a time, then waits for you. Keys: Space or → next, ← back, R repeat, P pass, F fail, B blocked, S skip, Esc stop.
  • Every test also has a Read aloud button.
  • The page talks with the browser's built-in voices. It does not listen: answers are given with keys or buttons, so it never competes with Vox for the microphone.

What is not built yet (do not test these)

  • Reading your screen (OCR), and controlling other windows or the browser.
  • Coding jobs on Windows (they report "not supported").
  • Wake word and Ambient mode are only partly built; Ambient mode only shows a notification. Realtime voice has been tested only against mock servers. Report what you see; a limited result is expected.
  • Spoken roles and lessons, and the agent hand-off with voice cancel, are built in the build from branch feature/voice-agent-conversation. You need that build installed, the hand-off setting on and an ACP agent configured. Spoken approval of agent permission prompts is planned and not built yet (Stage 3); those tests are skipped until it ships.
  • Voices with accents in their names (for example Amélie, Tünde, Mónica) are intentionally not in the voice list.

Your saved progress

Test ids never change when this page is updated, so your answers always stay attached to the right tests. Anything that no longer matches a test is kept at the bottom of the page and in the report, never deleted. Loading a file or restoring a backup first saves what you have now as a backup.

Where is each setting? search

  • Experimental features is one switch: Advanced tab, App card, Experimental Features (the last row). Off hides the experimental controls on the General, Models and Agents tabs; on shows them.
  • Post Process tab: holds the post-processing provider and model. The switch that turns post-processing on is Post Processing in the Engine & input group of the Advanced tab.
  • Debug page: press Cmd+Shift+D inside Vox (again to hide it).
  • Vox shows group titles in CAPITAL LETTERS. Most experimental groups start closed: click the title bar to open one. Vox remembers which ones you opened.
  • A greyed-out row depends on another switch. The table says which one. Some rows only appear once their parent switch is on.
  • Every test below also shows a blue Where to click box built from this same table.
