Gold-Siri Hybrid — Refined (more gold AND more color)

Applying your pick

  1. Export the chosen SVG card above as a 1024×1024 PNG (any browser "save SVG as PNG" tool, or I can do it for you with Pillow — same method the Python Vox icon generator uses).
  2. Run bun run tauri icon path/to/chosen.png from the Rust Vox repo root — regenerates .icns, .ico, and every platform size in one shot.
  3. macOS icon cache tip (this is likely why the gold icon "isn't showing" yet): macOS aggressively caches app icons by path. After replacing /Applications/Vox.app, run: 
    touch /Applications/Vox.app
killall Dock
killall Finder
    or, for a guaranteed clean slate, delete and re-copy the .app under a brand-new filename once, then rename it back.

Full Autonomous Assistant — Suggested Roadmap

Your Python vox repo already prototypes most of this. Suggested order to port/build it into the Rust Vox app, building on the dictation foundation already shipped and the Phase 1 (Memory) groundwork already on phase/1-memory.

SHIPPED

Dictation core

VAD, Whisper/Parakeet transcription, global shortcuts, paste injection, model management. The foundation everything else sits on.

IN PROGRESS

Phase 1 — Memory

Deterministic SQLite fact store (remember/recall/forget). Built, tested, on its own branch — needs a PR merge before anything can build on it.

NEXT

Phase 2 — Command Router + Safety Gate

Deterministic "open X / go to Y" command matching with a confirmation gate before anything destructive runs. Already spec'd in docs/vox-phases/.

NEXT

Phase 3 — Agent Bridge

Headless subprocess bridge to a user-configured coding-agent CLI for anything the router can't handle deterministically.

LATER

Phase 4 — Native TTS

AVSpeechSynthesizer-based spoken replies — turns Vox from "dictation tool" into something that actually talks back.

LATER

Phase 5 — Wake Word

ONNX/openWakeWord-style "Hey Vox" detection — the thing that makes it feel autonomous instead of hotkey-driven.

LATER

Phase 6 — Ambient Mode

Rolling transcript + engagement judge — decides when to actually jump in vs. silently listen. Highest-risk/most-novel phase.

LATER

Phase 7 — Vision / Screen OCR

Opt-in Apple Vision screen reading, so Vox can answer "what's on my screen" — privacy-sensitive, opt-in only by design.
